# Student Performance Analyzer 🎓

A Python project that analyzes student marks and displays their performance.

## 📌 Features

- Calculates total marks
- Calculates average marks
- Finds the top-performing student
- Displays student performance
- Creates a performance chart

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

## 📂 Project Structure

student-performance-analyzer/
- student_analysis.py
- requirements.txt
- README.md
- data/
  - students.csv

## ▶️ How to Run

Install the required libraries:

    pip install -r requirements.txt

Run the program:

    python student_analysis.py
